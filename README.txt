1. Create a free account at github.com, then a new repository (e.g. "VolteApp").
2. Upload ALL files from this folder (including the hidden .github folder) to it.
   Easiest: on the repo page choose Add file > Upload files, drag the unzipped folder contents in. 
3. Open the Actions tab > "Build APK" > Run workflow (it also runs on upload).
4. When it finishes (about 3-5 min), open the run, download the "VolteApp-apk" artifact, unzip, install app-debug.apk.
5. On the phone: install Shizuku, start it (Wireless debugging), open "Pixel VoLTE", tap Enable VoLTE.
